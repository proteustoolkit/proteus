# The state contract inventory: for every time integrator (TI), shock capturing (SC), subgrid error (SG),
# model step controller (STEP) and system step controller (SO) class, how a hot start treats its history.
# test/test_state_contract.py keeps this file complete and consistent with the code; a new class fails it
# until it is added here.
#
#   state       defines state()/set_state(): archived per rank in solver_state/ and restored after the spin-up
#   rebuilt     carries history that the spin-up rebuilds from the solution, and a hot start MEASURED to
#               continue exactly without its own state, given the state of the other owners of the model
#               (test/test_hotstart_state.py: backward Euler, and RKEV with its lagged shock capturing;
#               test/hotstart_measure with HS_RD_LAG=1: mprans.RDLS.ShockCapturing, 1e-16 on every field;
#               test/test_hotstart_rans3pf.py: mprans.RANS3PF.SubgridError and Min_dt_cfl_controller, bit-identical given the state of the rest;
#               the vortex2D backward Euler hot start, 1e-16: Min_dt_controller, Newton_controller, MCorr.Newton_controller, Sequential_MinModelStep)
#   follows     carries no history of its own: it re-derives its next step from a restored object
#               (the FLCBDF controllers read the restored integrator, syncAfterRestore)
#   unmeasured  may carry history; a hot start rebuilds it from the restart state and nobody has measured
#               what that costs. Moving a class out of here means measuring it (test/hotstart_measure).
#
