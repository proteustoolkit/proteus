# The state contract inventory: for every time integrator (TI), shock capturing (SC), subgrid error (SG),
# model step controller (STEP) and system step controller (SO) class, how a hot start treats its history.
# test/test_state_contract.py keeps this file complete and consistent with the code; a new class fails it
# until it is added here.
#
#   state       defines state()/set_state(): archived per rank in solver_state/ and restored after the spin-up
#               (BackwardEuler's state is m_last, and BackwardEuler_cfl's also dtLast; PsiTCtte, PsiTCtte_new, SSP,
#               the RKEVs and TADR's CompatibleBackwardEuler inherit it, which does not say that they carry nothing
#               more. Measured by test/test_hotstart_levelset.py, with the kernels.RANS2P shock capturing and
#               subgrid error lag machines and NumericalSolution's own owners: the coupled fields, the solver's
#               unknowns and the next system step; and with CLSVOF, and on rising_bubble_rans3p with the
#               kernels.VOF3P and NCLS3P shock capturing lag machines)
#               The delayed-lag shock capturing of kernels.Dissipation and Kappa is measured end to end by test_state_oracle.py
#               (damBreakLevelSet turbulence=1: dofs 7.5e-10 / 2.5e-10 off one interval after a hot start before, bitwise
#               after); kernels.TADR, VOS3P and RANS3PSed carry the same machine (DelayedLagState) and are tested only by
#               test_delayed_lag_state.py: no deck of theirs has been hot started yet. kernels.SW2D's (the same machine, in
#               kernels/SW2D.py, track B1's file until cekees/proteus#358 merges) is still `unmeasured`.
#               ShockCapturing.ResGradQuad_SC (and ResGrad_SC, HamiltonJacobi_SC: LaggedNumDiffState, the array the residual
#               reads, written back in place) is measured by test_state_oracle.py on test/ci/ladr_2d (lag=True): dofs
#               0.07-0.12 off one interval after a hot start before, bitwise after; the other two are the same code, no deck.
#               SubgridError.AdvectionDiffusionReaction_ASGS, HamiltonJacobi_ASGS and HamiltonJacobiDiffusionReaction_ASGS with
#               lag=True (LaggedSGEState: tau_last and the lagged *_sge arrays, written back in place; HamiltonJacobi_ASGS_opt
#               has its own): the first is measured by test_state_oracle.py on test/ci/ladr_2d_sglag (dofs 3e-2 off one interval
#               after a hot start before, bitwise after); the other two are the same code, tested by test_lagged_sge_state.py.
#               The TransientSubscales variant tracks subscales too and stays `unmeasured`.
#               TimeIntegration LinearSSPRKintegration, LinearSSPRKPIintegration and SSPRKPIintegration (ExplicitRK_base) stay
#               `unmeasured` and no hot start can measure them today: the decks that select them are the vortex/rotation ones, whose
#               NCLS/VOF kernels fail to construct the integrator (no elementResidual yet, TimeIntegration.py:1833), and the DG decks
#               (test/dg, dambreak_1d dgpk), whose space has no readFunctionXdmf, so `-H` stops before the first step.
#               SplitOperator.ISO_fixed_MinModelStep's stepFailures is reset when the sequence is accepted (it kept the count for
#               the whole run); it carries nothing else and stays `unmeasured` until a gwvd deck is hot started.
#               kernels.Richards.ThetaScheme carries rho_nodal_old and use_rho_nodal_old with m_last (the nodal density of the
#               last accepted step, the next step's old-time mass); and kernels.TADR.Coefficients (an owner outside this
#               inventory's five families, SOLVER_STATE_OWNERS) carries q_v, the carried mass M_dof and nodal density
#               rho_nodal of the edge-flux modes, and the Compatible scheme's carriedStorage. All measured on
#               test/salinity/levee_small (density-coupled TADR on Richards; test_state_oracle.py levee_small, _ev4, _ev5):
#               each removed in turn fails its deck, with the owners in, the dofs are bitwise one interval after a hot start.
#               kernels.RANS2P.Coefficients also carries q/ebqe eddy_viscosity_last when a turbulence closure is on (the kernel
#               lags it, LAG_LES; test_state_oracle.py damBreakLevelSet_smagorinsky: 4e-3 off at the restore, the velocity
#               dofs 4.6e-4 off one interval later, bitwise with it). Richards' u_dof_old needs no state (the four levee decks
#               with the flow on FCT are bitwise without it; ImplicitEV + implicit FCT is bitwise on Linux CI and 4e-16 off on
#               macOS arm64, last-bit platform noise: not gated).
#   rebuilt     carries history that the spin-up rebuilds from the solution, and a hot start MEASURED to
#               continue exactly without its own state, given the state of the other owners of the model
#               (test/test_hotstart_state.py: backward Euler, and RKEV with its lagged shock capturing;
#               test/hotstart_measure with HS_RD_LAG=1: kernels.RDLS.ShockCapturing, 1e-16 on every field;
#               test/test_hotstart_rans3pf.py: kernels.RANS3PF.SubgridError and Min_dt_cfl_controller, bit-identical given the state of the rest
#               (RANS3PF.SubgridError also on rising_bubble_rans3p, where it switches to lagging: test_hotstart_levelset.py);
#               the vortex2D backward Euler hot start, 1e-16: Min_dt_controller, Newton_controller, MCorr.Newton_controller, Sequential_MinModelStep)
#   follows     carries no history of its own: it re-derives its next step from a restored object
#               (the FLCBDF controllers read the restored integrator, syncAfterRestore)
#   unmeasured  may carry history; a hot start rebuilds it from the restart state and nobody has measured
#               what that costs. Moving a class out of here means measuring it (test/hotstart_measure).
#
# Not restored, by decision (cekees, 2026-11-06): the dof history's dof_last_last (FemTools.FiniteElementFunction).
# An archive hot start shifts the dof history twice before its first step (before the stepping loop and at the
# step), so there dof_last_last equals dof_last, where the uninterrupted run holds the previous step's dofs; dof_last
# itself is exact. Nothing in the tree reads dof_last_last for a computation today (the PUMI adapt only transfers it,
# as *_old_old fields nobody reads); the PUMI hot start reloads it from its checkpoint and is right. A kernel that
# starts reading it must archive dof_last and skip the first shift on a continue hot start.
#
# The state oracle (state_oracle.py, test_state_oracle.py, state_oracle_allowlist.txt) measures a hot start on whole decks
# without reading a class: every array and scalar the models hold, hot start vs the uninterrupted run, by attribute path.
# Its `gap` rows are the decks where an owner is known not to be restored (C14 note, section 3).
#
