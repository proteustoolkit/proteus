# Differences the state oracle (state_oracle.py) accepts, per deck. Gated: the values that still differ at the LAST dump
# of a deck's run, one output interval after the hot start (the restore instant, dump 0, is reported, not gated: most of
# what differs there is recomputed before it is read). Format, one row per line:
#   deck | pattern | kind | owner row | reason
# pattern: fnmatch over attribute paths; use `*` only (a `[` in a pattern is a character class, not a bracket).
# kind:
#   noise    not state: evaluation counters, memory nobody initialised
#   derived  recomputed from the restored state before it is read (say what makes it exact)
#   decided  a difference cekees decided to keep (the decision's date)
#   dead     an owner nothing reads (C14 note section 3: the sweep's "dead" rows, confirmed here by the run)
#   gap      the deck's hot start is NOT exact: an owner is not restored. A `gap` row with pattern `*` says the whole
#            deck is a known gap; the test then asserts that a dof still differs, and FAILS when none does, i.e. when
#            the gap is closed: remove the row. The owner row names the C14 note owner (3.2 row number or 3.5 letter).
# A row of a deck that matched nothing at the last dump is stale and fails the test (a `noise` or `decided` row may match nothing).
#
